# VVZ Studio website rules

- Read docs/faq-spec.md before making changes.
- Work only in this local repository.
- Never connect to or modify the production server.
- Preserve the existing static HTML/CSS/JavaScript architecture.
- Do not add frameworks, packages, CDNs, external APIs, LLMs, or dependencies.
- Do not modify Nginx.
- Do not modify the VVZ Lead System.
- Do not modify the contact-form endpoint in this task.
- Do not change js/script.js.
- Inspect js/faqbot.js and js/bot.js before editing.
- Prefer one shared runtime FAQ data source rather than duplicating answers in HTML and JavaScript.
- Edit only:
  - index.html
  - index-en.html
  - index-ru.html
  - js/faqbot.js
  - js/bot.js only if it is genuinely part of the current FAQ mechanism
  - one existing shared stylesheet only if minimal styling is required
- Preserve unrelated page content and behavior.
- Run syntax and structural checks.
- Show all modified files and git diff summary.
- Do not commit or deploy.
- Stop after local verification.
